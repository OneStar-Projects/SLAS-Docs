# SLAS 文檔（給客戶版）

本倉庫存放 **Student-Led Activities System（SLAS）** 對客戶開放的設計與操作文檔。

📖 **線上閱讀**：文檔已發布為網站，建議從站點瀏覽（有導航、全文搜尋，流程圖正常渲染）。

## 倉庫結構

```
docs/         所有文檔（Markdown）
mkdocs.yml    站點設定與導航
```

## 本機預覽

```bash
pip install -r requirements.txt
mkdocs serve        # http://127.0.0.1:8000
```

文檔分為**設計文檔**（功能與流程的設計邏輯）與**操作文檔**（步驟化指引），完整目錄見 [docs/index.md](docs/index.md)。
